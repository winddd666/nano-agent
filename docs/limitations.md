# 已知限制与待研究问题

这个版本用于实验记录和机制分析，以下问题仍保留为研究对象。

1. **工具可以正确运行错误模型。** 输入转录、条件理解、收益函数或答案索引有误时，程序退出为零不构成答案正确的证明。
2. **评审可能共享错误。** reviewer 可能接受错误解释、耗尽请求预算，或返回不符合严格 JSON 协议的内容；建议不是外部评分。
3. **有界诊断执行的覆盖边界。** `M1 + M2` 已消除长命令静默占满整题预算与黑盒硬超时强杀，但多层 Python `subprocess` 共享单栈文件时父进程栈可能覆盖子进程栈，且原生编译型二进制仅提供 `/proc` 活性而无 DWARF 栈帧。
4. **QA 与 coding 的任务适配已经分开，其他能力仍有限。** 当前没有网页搜索或浏览器工具；不能将选定文本 GAIA 题的表现推广到完整 GAIA。
5. **模型与环境未完全固定。** 当前 API 使用关闭 thinking、单次最大输出 2048 tokens 的配置，未显式设置 temperature/top_p/seed。服务端模型版本和默认采样仍可能变化。
6. **取消与预算耗尽的原因仍应分别解释。** 某些宿主信号路径会使用超时异常表示终止；研究记录应保留实际控制原因，不能把用户取消自动统计成自然超时失败。
7. **源码公开不等于历史环境已全部复现。** 老配置名不能替代源码版本；任务选择、工作区适配、预算、评分器和真实请求均属于实验条件。

后续改造应通过固定任务和条件的对照实验验证。当前不据个别案例规定固定反思周期、统一停止步数或强制工具调用数量。
